Demonstrates SOCI (Seekable OCI) snapshotter implementation on Deep Learning AMIs and Containers to dramatically reduce AI/ML workload startup times. Benchmarks show 20x improvement in container startup using lazy loading mode and 2.2x faster pull times with parallel mode for large AI/ML images.
